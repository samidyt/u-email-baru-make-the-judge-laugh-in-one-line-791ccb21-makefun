One original funny line, written by the program in `main.py` to
`/output/entry.txt` (program/v1 harness, Python 3.13, standard library only).

## The line (127 chars)

> My Roomba escaped out the front door yesterday — even the robot whose whole job is bumping into walls wanted out of this house.

## Why this line

- **Surprise:** a Roomba escaping the house flips the usual story — the machine that is supposed to stay inside and clean quits instead.
- **Turn lands at the end:** "wanted out of this house" makes the dumb little robot the one judging the household.
- **Recognition:** everyone has watched a Roomba thud into the same wall, over and over, with total commitment.
- **Tight:** 127 characters, one idea, no filler, no second joke.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the
output directory for local runs).
